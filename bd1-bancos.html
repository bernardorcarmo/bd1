Bancos de exemplo da P2

O script cria os seis bancos da apostila, cada um num esquema próprio. Copie, cole num PostgreSQL que rode no navegador e faça os exercícios sem instalar nada.

O navegador não deixou copiar. O texto está selecionado abaixo: pressione Ctrl+C.

  1. Abra o PostgreSQL Playground da Aiven. É PostgreSQL de verdade, rodando no navegador, sem conta.
  2. Cole o script inteiro (ou só o banco que vai usar, nos botões abaixo) e execute. Rodar de novo apaga e recria tudo.
  3. Antes de consultar, escolha o banco: SET search_path TO scott; (ou empresa, fornec, banco, univ, cursos).
O Playground não guarda nada ao fechar a aba: guarde as suas consultas num arquivo de texto e, na próxima vez, cole o script de novo antes delas.

Os seis bancos

Cada botão copia um banco sozinho. Depois de rodar, ele já fica selecionado (o próprio trecho faz o SET search_path).
